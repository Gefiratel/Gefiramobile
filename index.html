Gefira mobile

Un affichage adapté au téléphone pour Gefira (IRA de Bastia). L'installation se fait en trois étapes, dans cet ordre.

1. Installer Tampermonkey

C'est l'extension qui fait fonctionner le script. Touchez « Ajouter à Firefox », puis confirmez.

Ouvrir Tampermonkey

2. Installer le script

Tampermonkey affiche une page d'installation : touchez « Installer ». Le script est activé tout de suite, et se met à jour tout seul.

Installer le script

3. Ouvrir Gefira

Connectez-vous comme d'habitude : la page s'affiche avec la nouvelle présentation.

Ouvrir Gefira

À l'étape 2, si du texte s'affiche au lieu d'une page d'installation, c'est que Tampermonkey n'est pas encore actif : reprenez l'étape 1. Cette méthode fonctionne avec Firefox sur Android (et avec Tampermonkey sur ordinateur). Elle ne fonctionne pas avec Chrome sur Android ni sur iPhone.
